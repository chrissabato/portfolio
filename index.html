Dakbot

MicroPython firmware for an ESP32-S3-ETH board that reads live scoreboard data from a Daktronics AllSport 5000 controller and serves it as JSON over Ethernet. Monitors RTD serial packets at 19200 baud and supports baseball, basketball, volleyball, football, and hockey/lacrosse.

GitHub – Dakbot (opens in new tab) Blog Post – Dakbot (opens in new tab)

Self-hosted, multi-user TV show tracker — a lightweight TV Time clone. Vanilla JS PWA frontend backed by a PHP + SQLite API using TMDB for show data, with Google sign-in behind an admin-managed allowlist, per-episode/season watched tracking, and an infinite-scroll episode calendar.
